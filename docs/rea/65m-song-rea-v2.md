ข้อมูลที่ได้จากการเล่นจริงรอบนี้ (ยืนยันสิ่งที่ v1 อ่านจากโค้ด):
- หน้าสรุปเรียง: ป้าย "สรุปชีวิต · ชื่อ · อายุ" → คะแนนใหญ่ (69) → "ชีวิตนี้ดีกว่าคนไทย 88%" → กล่อง archetype (เช่น "ชีวิตสมดุล" + คำอธิบาย 1 บรรทัด) → "เทียบกับชีวิตจำลอง 160 ชีวิตที่สุ่มเกิดตามสัดส่วนจริงและตัดสินใจแบบสุ่ม" → แถบส่วนประกอบคะแนนพร้อมน้ำหนัก (ความสุขเฉลี่ย ×0.3, สุขภาพเฉลี่ย ×0.25, ทรัพย์ที่ส่งต่อ ×0.2, บุญ/บาป ×0.2, เส้นสาย ×0.05, กรรมดีออกผล +N) → การ์ด + "กดค้างที่การ์ดเพื่อบันทึกภาพ" + ปุ่ม "คัดลอกข้อความ" → "ไปต่อ" → หน้าชีวิตถัดไป (เล่นต่อเป็นลูก / เกิดใหม่ชาติหน้า (บุญบาปขยับโอกาสฐานะ) / เริ่มชีวิตใหม่)
- ตัวเลือกที่ทำไม่ได้แสดงพร้อมกุญแจและเหตุผล เช่น "🔒 ไม่มีทุ่งเลี้ยงวัว" (ตรงกับ v1)
- ชีวิตหนึ่งจบใน ~50 การกด ถ้ากดเร็ว เล่นจริงราว 5–10 นาที (สั้นกว่า 1in8b ซึ่งตั้งไว้ 30/60/90 นาที)

## สรุปการออกแบบที่ยังใช้ได้ (ซ้ำจาก v1 แบบย่อ)
- โอกาสเกิดจากตารางประชากรจริง (จังหวัด × ฐานะ) แสดงทั้ง distribution ("บันได" 6 แท่ง แท่งของคุณสีทอง)
- กรรมซ่อนจนตาย แล้วเปิดบัญชีกรรมทีละแถว 0.25 วิ ทอย "ปะทุ/รอด", "ออกผล/เงียบ"
- archetype ราว 30 แบบ (rare สีทอง 1 แบบ) + percentile เทียบชีวิตจำลอง 160 ชีวิตที่รันตอนเปิดเว็บ
- การ์ด 600×750: พื้นไล่สีน้ำเงินม่วง 4 แถบ, ดาวสุ่มแบบ seed `mulberry(age*7+guests)`, กรอบทองประ, ตัวละครพิกเซลขยาย 8×, ชื่อ (+รุ่นที่), จังหวัด·ฐานะ / อาชีพ / อายุขัย·แขกงานศพ, archetype ใน 「」, "ชีวิตนี้ดีกว่าคนไทย" + ตัวเลข % 88px, บรรทัดตระกูล "จาก Q1 สู่ Q4", ชื่อเกมท้าย
- ข้อความคัดลอก: ประโยคเดียวสรุป จังหวัด ฐานะ อาชีพ อายุ แขกงานศพ + "ดีกว่าคนไทย N%" (+ รุ่นที่)
