   - การ์ดแรกเกิดก็เป็น 1080×1350 แชร์ได้ตั้งแต่ก่อนเล่น (ลิงก์ `/s/b-…`)

### 2.4 ฉากจบ (`playEnding`) ลำดับเวลาที่วัดจากโค้ดและที่เห็นจริง
overlay เต็มจอพื้นเข้ม เพลงลดเหลือ 45% ปุ่ม "ข้าม" ต้องกดสองครั้ง (ครั้งแรกเปลี่ยนเป็น "กดอีกครั้งเพื่อปิด" 3 วินาที) แตะจอ = ข้ามไปจังหวะถัดไป (ต้องห่างอย่างน้อย 0.9 วิ) Esc = ปิด
1. **หัว**: บรรทัดใหญ่ `head` (1.8 วิ) → การสูญเสียครั้งสุดท้ายถ้ามี (2.6) → "จากไป…" + ป้ายสาเหตุเล็ก (2.2) → คำพูดสุดท้ายถ้ามี (2.6) → "หลับตาลง วันเวลาที่ผ่านมาก็ไหลผ่าน" (2.6)
2. **Montage**: ภาพพิกเซล 192×108 สองแคนวาสสลับ crossfade เปลี่ยนภาพ 0.42 วิ แล้วค้าง `2.1 + min(1.5, ความยาวข้อความ×0.02)` วิ ใต้ภาพมี "อายุ N ปี" ตัวห่าง + ข้อความ และ **แถบปีเป็นจุดๆ ติดไฟทีละช่องตามอายุ** (ดู `1in8b-v2-ending-montage.png`)
3. **งานศพ**: ฉากพิกเซลพิธีตามศาสนา + คนมาส่ง (จำนวนและวัยตามจริง) · บรรยายพิธี (3.2) · ใครมาบ้าง (3.8) · คำไว้อาลัยจากลูก/คู่ (3.4)
4. **Epitaph**: ชื่อใหญ่ · ปีเกิด–ตาย mono · 2–3 บรรทัด (เกิดที่ไหน หลับที่ไหน / มีชีวิต N ปี หรือราว X วัน / ฝากลูก หลาน เหลนไว้) ทีละบรรทัด 1.1 วิ · คำคมที่ผู้เล่นเขียนไว้ถ้ามี · บรรทัดปิด "ในบรรดา 8 พันล้านคน นี่คือชีวิตที่มีเพียงครั้งเดียว" · ปุ่ม "ดูบันทึก"

### 3.3 ข้อความแชร์ (`shareText`)
สร้างจากส่วนประกอบที่มีลำดับความสำคัญ `p` (ต่ำ = สำคัญ) และลำดับแสดง `o`:
| p | ส่วน | o |
|---|---|---|
| 0 | บรรทัดความรู้สึกของผู้เล่น | 0 (บนสุด) |
| 1 | เกิด: "(ปีเกิด ถ้าเลือกโลกอดีต) เกิดเป็นเด็กผู้หญิงในครอบครัว<ฐานะ>ที่<เมือง ประเทศ>" | 10 |
| 1 | ตาย: "…ทำงานเป็น<อาชีพ>แล้วจากไปด้วย<สาเหตุ>เมื่ออายุ N ปี" หรือแบบเกษียณ/ไม่ถึงขวบ (ไม่ใส่สาเหตุถ้าฆ่าตัวตาย) | 45 |
| 2 | ถูกรับเป็นบุตรบุญธรรม | 11 |
| 2.5/4/5 | hook อันดับ 1/2/3 | ตาม hook |
| 2 | คำอำลา “…” | 70 |
| 3 | คำถามชวน (สุ่มจาก 4 แบบด้วย seed) + `#1 ใน 8 พันล้าน` | 90 |
| 6 | ย้ายประเทศ / "ตั้งอนุสรณ์แล้ว แวะไปดูห้องกับอัลบั้มหน่อย" | 12 / 75 |

Hook (`shareHooks0`) แต่ละตัวมีคะแนน `s + (hash(ชื่อ+ประเทศ+อายุ+id) % 1000)/400` คือคะแนนฐาน + jitter คงที่ต่อชีวิต แล้วตัดซ้ำตามกลุ่ม:
- `star` 30: ช่วงเวลาที่ผู้เล่นติดดาว ☆ ล่าสุด "ช่วงเวลาที่อยากจำ อายุ N: “…”"
- `dream` 9/7/4.5: ฝันวัยเด็กเทียบงานจริง (ทำได้/เคยทำ/สุดท้ายเป็นอะไร)
- `road` 4–10: เส้นทางชีวิตหนึ่งประโยค · `lands` 4+จำนวนประเทศ
- `odds` 5 ถ้าสุดขั้ว (<12% หรือ >75%) ไม่งั้น 2.5: "เด็กเกิดปีเดียวกัน X% อายุยืนกว่าฉัน" (ในตัวอย่างจริงอยู่บรรทัดแรก)
- `pt` 2–7: อยู่กับคู่ ≥30 ปี · `kin` 3–9: หลาน/เหลน · `happy` 4: ปีที่สุขที่สุดและเพราะอะไร · `said`/`last` คำไว้อาลัย/คำพูดสุดท้าย · `comps` 3 · `tal` 2.5 · `hob` 3

งบตัวอักษร: X ใช้ 256 แบบถ่วง (ตัวอักษร CJK และสัญลักษณ์บางกลุ่มนับ 2) ไม่ใส่ URL ในเนื้อ (ส่ง `&url=` แยก) · ที่อื่น 480 ตัวรวม URL · ส่วน p≤1 ใส่เสมอ ที่เหลือใส่ตามลำดับความสำคัญจนเต็ม แล้วเรียงตาม `o` แฮชแท็กต่อท้ายบรรทัดคำถาม

ตัวอย่างโครง (ชีวิตจริงที่เล่น): บรรทัด odds → บรรทัดเกิด → ปีที่สุขที่สุด → ลูก 3 คน → บรรทัดตาย → คำถามชวน + แฮชแท็ก → ลิงก์ `/th/s/d-IND-52-F-u-k3`

Intent: X `https://x.com/intent/tweet?text=…&url=…` · Threads `https://www.threads.net/intent/post?text=…` (ข้อความรวมลิงก์) · ไม่มีปุ่ม LINE/Facebook ตรง ใช้ native share แทน
