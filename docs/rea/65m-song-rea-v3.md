## รายละเอียดกลไก

### 1. ค่าสถานะมีผลทุกปี (`statYear`, `statWorkF`, `statNote`)

`years()` เรียก `statYear(p, notes)` ทุกปีตั้งแต่อายุ 15 ผลแบ่งตามช่วงค่า:

- รายได้คูณ `statWorkF`: H < 35 คูณ `0.75 + H/140` (H = 0 เหลือ 75%), H ≥ 75 คูณ 1.05, J < 25 คูณ 0.9
- H < 35: เสียเงิน `(35−H)×600` บาทต่อปี (ปรับตามฐานะด้วย `lm`)
- J < 25: ปีละ 8% ติดสถานะซึมเศร้า, 30% H −1 · J ≥ 75: H +0.5 และ 25% C +1 · ซึมเศร้าหายเมื่อ J ≥ 55 ปีละ 25%
- เฉพาะคนทำงาน (22-59 ปี มีอาชีพ ไม่ติดคุก): S ≥ 70 มีโอกาส `0.03 + (S−70)×0.003` ต่อปีได้ขึ้นค่าตัว ×1.06 (ยกเว้นเกษตรกร สายมืด นักการเมือง), S < 30 ในงานออฟฟิศ/โรงงาน/ธุรกิจ/อินฟลู ปีละ 5% โดนลดบทบาท ×0.95, ตกงานแต่ C ≥ 65 มี 50% ได้งานทันที, C < 20 J −1 ต่อปี
- `statNote` กันข้อความซ้ำ: คีย์เดียวกันขึ้นได้อย่างมาก 1 ครั้งทุก 5 ปี
- ในรอบที่เล่น เห็นบรรทัด "สุขภาพไม่ดี ลาป่วยบ่อยจนรายได้หาย…" ขึ้นในหน้ากระโดดเวลา (`65m-v3-timeskip-world.png`)

ประเด็นออกแบบ: ค่าสถานะเคยเป็นแค่ตัวเลขที่ใช้ตอนทอย ตอนนี้มันส่งผลระหว่างทางและเกมบอกผู้เล่นตรงๆ ว่าเกิดอะไรขึ้นเพราะค่าไหน

### 2. บ้านเมือง (`wld`, `addMod`, `worldYear`, `WORLD_EVENTS`)

- สถานะโลกเก็บใน `p.world = {party, junta, nextElec, mods[], seen{}, last}` เริ่มตอนอายุ 18
- ตัวปรับ (mod) แต่ละอันมี `inc` (ตัวคูณรายได้ต่ออาชีพ หรือ `all`), `tier` (ตัวคูณต่อภูมิภาค), `cost` (ค่าครองชีพ), `risk` (คูณความเสี่ยงโดนจับผ่าน `connRisk`), `cash` (เงินช่วยเหลือต่อปี), `until` อายุที่หมด และ `endText` ตอนหมดอายุ
- เอาไปใช้ใน `years()`: รายได้ × `worldIncomeF`, ค่าครองชีพ × `worldCostF`, + `worldCashYear`
- ลำดับต่อปี: ถ้าไม่มีรัฐบาลทหาร อายุ ≥ 20 มีโอกาส 2% เกิดรัฐประหาร → ถึงรอบเลือกตั้ง (`nextElec` เริ่มที่ 18-21 แล้วทุก 4 ปี) → ห่างจากเหตุการณ์ก่อน ≥ 3 ปี มี 14% สุ่มเหตุการณ์โลก 1 เรื่อง (แต่ละเรื่องเกิดได้ครั้งเดียวต่อชีวิต น้ำหนักขึ้นกับอาชีพ/อายุ/ภูมิภาค)
- รัฐประหาร: งดเลือกตั้ง 4-6 ปี ตัวปรับธุรกิจ ×0.92 อินฟลู ×0.9 ข้าราชการ ×1.05 ความเสี่ยง ×1.2 ถ้าเป็น ส.ส. หลุดตำแหน่ง
- `modText(p, m)` เขียนผลเฉพาะตัวผู้เล่น เช่น "รายได้คุณ −15% · ค่าครองชีพ +3%" (ไม่แสดงตัวปรับที่ไม่กระทบอาชีพตัวเอง)
- `worldHTML(p)` ใส่บรรทัด "📌 บ้านเมืองตอนนี้: รัฐบาลรักษ์ระเบียบ (ค่าครองชีพ −1%)" ในหน้ากระโดดเวลา (เห็นจริงในรอบที่เล่น)
- ตัวเลือกในเหตุการณ์โลกบอกโอกาสเป็นตัวเลขที่คำนวณจากค่าสถานะ เช่น ช้อนหุ้น `0.55 + 0.004×(S−50)` แสดง "52% ได้ ×1.8 ใน 3 ปี"

### 3. เลือกตั้ง (`PARTIES`, `PARTY_W`, `PARTY_POLICY`, `election`)

- 4 พรรค: อิ่มท้อง (แจกเงิน 10,000, ค่าแรงโรงงาน +6%, พักหนี้เกษตรกร, ค่าครองชีพ +3%), เงินสะพัด (ธุรกิจ +10%, ภูมิภาค 1-2 ได้เพิ่ม), กระจกใส (ปราบโกง risk ×1.4, เบี้ยยากจน/ผู้สูงอายุ 12,000/ปี, ข้าราชการ −3%), รักษ์ระเบียบ (ข้าราชการ +8%, ค่าครองชีพ −1%, risk ×1.3)
- ถามผู้เล่นในครั้งแรก ครั้งเลขคู่ และทุกครั้งถ้าเป็นนักการเมือง ครั้งที่ไม่ถามใช้พรรคเดิมที่เคยเลือก
- หัวคะแนนมาเสนอเงินด้วยโอกาส 45% (ภูมิภาค ≥ 4) หรือ 25%: รับแล้ว K −3 และติดป้ายบาป `corrupt`
- ผู้ชนะสุ่มจาก `PARTY_W[พรรค][ภูมิภาค]` + 0.05 ให้พรรคที่ผู้เล่นเลือก − 0.03 ให้พรรคที่ครองอยู่ นโยบายเป็น mod 4 ปี

### 4. นักการเมือง (`CAREERS.pol`, `polStart`, `polCampaign`, `polAfterElection`, `polYear`, `POL_EVENTS`)

- เข้าได้เมื่อ `polEntry`: C ≥ 50 หรือเกิดฐานะ ≥ 4 หรือมี `polLink` หรือเป็นข้าราชการ หรือเป็นเจ้าพ่อ (`crimeRank ≥ 2`) ห้ามมีประวัติติดคุก ค่าสมัคร 300,000
- `polLink` ได้จากหลายทาง: อินฟลูเอนเซอร์ที่ผลดี, ขึ้นเป็นเจ้าพ่อ, คลิปไวรัล, แมวมอง, นายกสโมสรนักศึกษา, เป็นแกนนำชาวบ้าน, ผู้ใหญ่รับเป็นศิษย์ (30%)
- รายได้ตามขั้น 25k / 70k / 125k / 220k ต่อเดือน นอกตำแหน่ง 12k
- โอกาสชนะ = `0.4 − 0.07×ขั้นเป้าหมาย + 0.006(C−50) + 0.003(S−50) + 0.002K` + 0.1 ถ้าป้องกันที่นั่งเดิม + 0.05 ถ้าพรรคตัวเองครองรัฐบาล ตัดที่ 5-92%
- วิธีหาเสียง: เดินเคาะประตู (ฟรี H−3, S ช่วย), โฆษณา (+12% จ่ายเงินคูณ 1/3/8 ตามขั้น), ขอบ้านใหญ่หนุน (+18% ต้อง C ≥ 60 ติดหนี้บุญคุณ), ซื้อเสียง (+25% เสี่ยงใบแดง 15% ปรับตามเส้นสาย)
- แพ้ 2 ครั้งติดให้เลือกสู้ต่อหรือวางมือ, เป็น ส.ส. แล้วพรรคชนะมีโอกาสได้เป็นรัฐมนตรี `0.3 + 0.006(C−50) + 0.1(สมัย−1)`, พรรคแพ้ก็หลุดเก้าอี้
- ทุกปีมีโอกาสโดน ป.ป.ช. ตามจำนวนป้าย `corrupt` × ขั้น แล้วติดคุก 2+ขั้น ปี
- เหตุการณ์เฉพาะ 7 เรื่อง สุ่ม 3 เรื่องใส่ช่วง 2-16 ปีหลังเริ่ม: เงินทอนผู้รับเหมา, งูเห่า, น้ำท่วมในเขต, ดึงงบเข้าบ้านเกิด, บ้านใหญ่ทวงบุญคุณ, สื่อขุดประวัติ, ถูกขู่ฆ่า (8% ตายถ้าไม่จ้างบอดี้การ์ด)
- archetype ใหม่: "รัฐมนตรีจาก<จังหวัด>" (rare สีทอง), "นักการเมืองหลังลูกกรง", "ผู้แทนราษฎร", "นักการเมืองท้องถิ่นตัวจริง", "ผู้สมัครที่ไม่เคยชนะ"

### 5. จุดพลิกผัน (`twistBeats`, `TWISTS`, `TWISTS_YOUNG`, `TWISTS_OLD`)

- วัยเรียน 1 เรื่อง อายุ 18-21 จาก 4 (แมวมอง, นายกสโมสร, พนันบอล, ทุนแลกเปลี่ยน)
- วัยทำงาน 3 เรื่อง อายุ 24-58 จาก 16 (ไฟไหม้บ้าน, เก็บกระเป๋าเงิน, คลิปไวรัล, บริษัทต่างชาติทาบทาม, หนี้ค้ำประกัน, เพื่อนชวนลงหุ้น, เจอทุจริตในที่ทำงาน, รถชน, ก้อนเนื้อ, เวนคืน, ค้นพบงานที่รัก, รักเก่า, ผู้ใหญ่เห็นแวว, บัญชีม้า, มรดกญาติห่างๆ, แกนนำชาวบ้าน)
- วัยชรา 1 เรื่อง 62 ถึงอายุขัย จาก 4 (งานเลี้ยงรุ่น, หลานติดหนี้พนัน, รักแรก, ผู้อาวุโสชุมชน)
- ทุกเรื่องมีตัวเลือก 2-4 ทาง แต่ละทางบอกผลหรือโอกาสที่คำนวณจากค่าสถานะในบรรทัดย่อย เช่น "ร่างกายคุณไหว"/"สุขภาพไม่ดี เสี่ยงสำลักควัน" ตาม H ≥ 60
- บางเรื่องเปลี่ยนอาชีพกลางทาง (ไวรัล → อินฟลูเอนเซอร์, ค้นพบงานที่รัก → ธุรกิจ) แล้วตั้ง `outAt` ใหม่

### 6. พ่อแม่และข้อความตามสถานะ (`parentsAlive`, `ctxOf().carer/carerPast/mom/pw/dad`)

- รุ่นแรกถือว่าพ่อแม่อยู่ครบจนผู้เล่นอายุ 60 หรือได้มรดก (`parentsGone`)

### 7. ฉาก (`autoBg`, `sceneFinish`, ฉากใหม่, การ์ด)

- `autoBg(o, p)` มีกฎ regex 13 ข้อตามคำในหัวข้อ, หัวข้อเกี่ยวกับงานใช้ฉากของอาชีพ (`CAREERS[career].bg`), ไม่ตรงเลยใช้ hash ของหัวข้อเลือกจากกองฉากของช่วงวัย (ฉากจึงคงที่ต่อหัวข้อ ไม่กระพริบ)
- event เดิมหลายสิบอันเปลี่ยน `bg` จาก `home` เป็นฉากเฉพาะ (ครัว ตลาด ศาลา สนามบิน ข่าว ศาล)
- ศิลป์: backing store 2 เท่า, ตัวช่วยวาด `dr/dl/dp/dText` วาดครึ่งพิกเซลและ polygon, ฉากทุกฉากเขียนใหม่ (บ้าน 6 ระดับฐานะ, อาคารพื้นหลังตามภูมิภาค), รายละเอียดสุ่มใช้ seed เฉพาะที่ ไม่แตะ RNG ของการจำลอง
- การ์ด 900×1200: หัว "1 ใน 65 ล้าน" + "บันทึกชีวิต" → ฉากจบเต็มความกว้าง → รูปตัวละครในกรอบทอง → ชื่อ/บ้านเกิด → "ชีวิตนี้ดีกว่าคนไทย" + ตัวเลข % ขนาด 91px + แถบ → คะแนนชีวิต → archetype + คำอธิบาย 2 บรรทัด → 3 ช่อง อาชีพ/อายุขัย/คนมาส่ง → บรรทัดตระกูล → ท้ายการ์ด ฟังก์ชัน `fit()` ย่อฟอนต์จนพอดีความกว้าง
